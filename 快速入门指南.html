OpenClaw U盘便携版 v1.0.0

把AI助手装进U盘 · 插上即用 · 带走即走 · 所有数据跟你走

概览

OpenClaw U盘版是一款便携式AI助手解决方案。所有运行环境、数据、配置全部藏在U盘里，不会在目标电脑留下任何痕迹。换电脑也能无缝衔接。

快速上手
1

插入U盘，双击 OpenClaw.exe

等待几秒，浏览器会自动打开激活页面。如果已有有效账号，直接启动。

2

注册账号，充值 Token 额度

打开平台注册并登录，在后台充值获得额度，然后获取你的 API Key。

3

填入 API Key，点击"验证并启动"

激活页面验证通过后会自动保存配置并启动 OpenClaw。

4

开始使用！

浏览器打开 http://127.0.0.1:8080，看到 OpenClaw 界面即为成功 ✅

安全拔出 每次使用完毕，点击「彻底退出软件.exe」等待提示"可以安全拔出U盘了"后再拔盘，避免数据损坏。
免激活 下次在同一台电脑使用，直接运行 OpenClaw.exe 即可，无需再次输入 API Key，数据跟着U盘走。
4个工具

OpenClaw.exe

主程序入口，自动检测账号状态，有账号直接启动，无账号弹出激活页面

激活账号.exe

重新打开激活页面，用于切换账号或重新填写 API Key

急救与重置工具.exe

将配置文件恢复出厂状态，用于配置损坏时一键重置

彻底退出软件.exe

关闭所有进程并提示可以安全拔U盘，避免强行拔盘导致数据损坏

常见问题
Q

提示"未找到 Node.js 运行环境"

确保 U盘根目录下的 node/ 文件夹完整，没有被杀毒软件误删。

Q

激活页面打不开

检查 .system/logs/error.log 获取详细错误信息。也可运行「激活账号.exe」手动打开。

Q

API Key 验证失败

确认平台可以访问，且账号有充足余额。可联系管理员查询账号状态。

Q

配置损坏/无法启动

运行「急救与重置工具.exe」，将配置恢复出厂状态，然后重新激活。
