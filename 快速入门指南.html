这是什么？

OpenClaw U盘版，把AI助手装进U盘。插到任意Windows电脑，插上就能用，拔走就带走。所有数据跟着U盘走，不留痕迹。

30秒快速上手
1

插入U盘，运行 OpenClaw.exe

双击 OpenClaw.exe，等待启动（约5-10秒）

2

首次使用需要激活账号

如果没有账号，先打开平台注册：http://3295b30e.r8.cpolar.cn

3

获取API Key并填入激活页面

注册账号 → 充值额度 → 在后台获取 API Key → 填入激活页面 → 点击"验证并启动"

4

开始使用！

浏览器会自动打开 http://127.0.0.1:8080，看到OpenClaw界面即为成功 ✅

⚠️ 安全拔出：每次使用完毕，点击「彻底退出软件.exe」等待提示"可以安全拔出U盘了"后再拔盘，避免数据损坏。
💡 免激活：如果下次在同一台电脑使用，直接运行 OpenClaw.exe 即可，无需再次激活。API Key已保存在U盘中。

常见问题
Q

提示"未找到 Node.js 运行环境"

确保U盘根目录下的 node/ 文件夹完整，没有被杀毒软件误删。

Q

激活页面打不开

检查 .system/logs/error.log 获取详细错误信息。也可尝试运行「激活账号.exe」手动打开。

Q

API Key验证失败

确认平台网址 http://3295b30e.r8.cpolar.cn 可以访问，且账号有充足余额。

Q

配置损坏/无法启动

运行「急救与重置工具.exe」，将配置恢复出厂状态，然后重新激活。
